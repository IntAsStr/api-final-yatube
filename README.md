# api_yatube
api_yatube
Yatube API предоставляет RESTful интерфейс для взаимодействия с социальной платформой блогинга.
    API поддерживает:

        Аутентификацию по токенам

        Управление постами

        Работу с группами

        Комментирование постов

____________________Локальный запуск проекта__________________________________________________
1. Склонировать репозиторий. (git clone <repository_url>)
2. Установить зависиости requirements.txt (pip install -r requirements.txt)
3. Запустить проект командой python manage.py runserver (python manage.py runserver)

        Сервер будет доступен по адресу: http://127.0.0.1:8000/

___________________После запуска доступны следующие endpoints_________________________________
Раздел авторизации токена.

    Метод: POST

    Эндпоинт - api/v1/api-token-auth/

    Описание - Получение токена для авторизации

Раздел постов.

    Методы: GET, PUT, PATCH, DELETE

    Эндпоинты:
        api/v1/posts/  Получить список постов / создать новый
        api/v1/posts/{post_id}/  Получить/изменить/удалить пост

Раздел групп.

    Метод: POST

    Эндпоинт:
        api/v1/groups/	Получить список групп
        api/v1/groups/{group_id}/ Получить информацию о группе

Раздел коменнтариев к постам
    
    Методы: GET, PUT, PATCH, DELETE

    Эндпоинт:
        api/v1/posts/{post_id}/comments/	Получить/добавить комментарии к посту
        api/v1/posts/{post_id}/comments/{comment_id}/ Управление конкретным комментарием
